ToyPortal360 for Peer Pressure - setup
=====================================

Lets LEGO Dimensions, Disney Infinity and Skylanders on an Xbox 360 running
Peer Pressure use virtual figures instead of a real Toy Pad, base or portal.
Tested on a console with LEGO Dimensions (Games on Demand, title ID 5752084B),
Disney Infinity 3.0 (42560832) and Skylanders Imaginators (41560930). In
Imaginators, wait until you're past the title screen before opening the menu.

What you need
-------------
- An Xbox 360 with Peer Pressure, in its softmod (hacked) mode.
- A way to copy files to the console's hard drive (FTP or a USB stick and
  Aurora's file manager).
- Your game installed on the hard drive (Games on Demand or extracted).

1. Copy the plugin next to the game
-----------------------------------
Find the folder that holds the game's files. For a Games on Demand copy it
is the 00007000 folder inside the game's content folder, for example:

  Hdd1:\Content\0000000000000000\LEGO Dimensions [5752084B]\00007000\

(next to the long file such as 0E8BB02F8815451809DE and its .data folder).
For an extracted game it is the folder that holds default.xex.

Copy into that folder:
  - ToyPortal360-PeerPressure.xex
  - sideload.ini from NextToGame\<your game>\

Both files must sit directly in that folder, with exactly these names.
Do not edit sideload.ini: Peer Pressure ignored config files longer than
512 bytes and ones that did not start with a ; comment line.

2. Start the game the right way
-------------------------------
Peer Pressure only loads the plugin on the FIRST game started after the
console is switched on. So every time:

  1. Turn the console fully off (hold the power button until it shuts down,
     or unplug it for 10 seconds) and turn it back on.
  2. Start the game straight away, before any other game or app.

When the game looks for the Toy Pad you get a pop-up:
  "Toy Portal 360 ready - hold LB+RB+Back for the menu, LB+RB+Y for the grid"

3. Use the menu
---------------
In the game, hold LB + RB + Back to open the menu.

  Place     put one of your saved figures on the pad
  Remove    take a figure off
  More      Create a new figure, Move a figure to another pad spot,
            or switch emulation off (to use a real Toy Pad again)

To make a figure: More > Create, type part of its name (for example
gandalf or batman), pick it from the list, then Place it and choose a
pad spot (left, centre or right).

Character grid
--------------
Hold LB + RB + Y for a grid of every figure in the game.
  d-pad / stick   move        LB / RB   change page
  A               put the figure on (makes its file if you have none)
  A again         take it off
  LEGO Dimensions: A asks Left / Centre / Right. Pick with left/right,
                  then A. B goes back without placing. On a figure
                  that's on already, picking another pad moves it
                  and the fourth box, Off, takes it off.
  Quick move (LEGO Dimensions, grid closed): LB+RB + d-pad left / up /
  right moves the figure the grid last put on to the left / centre /
  right pad. For a Master Build, put Wyldstyle on with the grid, then
  quick-move her to each section the game's on-screen pad flashes.
  The toy pad's lights show in the footer (Pad L C R) and on the picker's
  boxes, with the colour's name, for puzzles like Master Build.
  B               close
Figures on the pad are green. If every spot a piece can use is taken, A
takes off the one that has been on longest and puts the new one there.
Tested on a console in LEGO Dimensions, Disney Infinity 3.0 and Skylanders
Imaginators. If the game shows through it, add  grid_size = small  to
toyportal.ini for a smaller, more solid grid.

Adding your own pictures
------------------------
Toy Portal 360 doesn't come with any character pictures, but the grid can
show your own, for example photos of your own figures:
  1. On a PC, name each picture after the figure as the grid shows it
     (Batman.jpg, Spyro.png).
  2. Convert them with make_pictures.py (in the PC folder of the download):
       python3 make_pictures.py <folder> Dimensions
     (or Skylanders / Infinity). It needs Pillow: pip install pillow
  3. Copy the .tpi files it makes to Hdd1:\ToyPortal\Pictures\<game>\
     and reopen the grid.
A picture the grid can't use is skipped (see log.txt).

Where figures are kept
----------------------
  Hdd1:\ToyPortal\Dimensions\   LEGO Dimensions (.bin, 180 bytes)
  Hdd1:\ToyPortal\Skylanders\   Skylanders (.sky / .bin, 1024 bytes)
  Hdd1:\ToyPortal\Infinity\     Disney Infinity (.bin, 320 bytes)

The game saves progress and upgrades into these files. You can also copy in
figure dumps made by other tools (for example RPCS3's) and Place them.

Settings are in Hdd1:\ToyPortal\toyportal.ini (made on first run). Set
log = 1 there to write Hdd1:\ToyPortal\log.txt if something goes wrong.

If nothing happens
------------------
- No pop-up: restart the console fully and start the game first. Check that
  both files are in the game's folder and named exactly as above.
- Other games: use the sideload.ini from NextToGame\<that game>\. Its title
  ID must match the game (press Guide in the game or check Aurora's game
  details). Games other than LEGO Dimensions, Disney Infinity 3.0 and
  Skylanders Imaginators have not been tried on a console yet.
- Disc copies have no game folder to copy into: use the SideLoading folder
  instead (copy its .ini files and the .xex to Hdd1:\PeerPressure\SideLoading\).
  That route has not been confirmed on a console yet.
